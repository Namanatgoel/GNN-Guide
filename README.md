# Graph Neural Networks: From First Principles to Advanced Systems

An interactive exploration and technical guide to Graph Neural Networks (GNNs), covering foundational topological formulations up through state-of-the-art spectral and attentional architectures.

## Topics Covered
- Relational topology and permutation equivariance
- Algebraic foundations, adjacency representations, and graph Laplacians
- Message Passing Neural Networks (MPNN) framework
- Kipf & Welling GCN spectral renormalization
- GraphSAGE inductive neighborhood aggregation
- Graph Attention Networks (GAT) dynamic attention distributions
- GraphGPS and expressivity limits beyond 1-WL
- Empirical benchmark evaluations (Zachary's Karate Club, Cora)

## Viewing Locally
Open `index.html` in any modern web browser or serve locally:
```bash
python3 -m http.server 8000
```
